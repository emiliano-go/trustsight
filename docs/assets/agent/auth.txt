# auth.md

The TrustSight documentation is **public and read-only**. It has no account
registration, no OAuth authorization server, and no bearer token requirement.

- Documentation: <https://docs.trustsight.org/>
- Product site: <https://trustsight.org/>
- Watcher read API: <https://watcher.trustsight.org/api>
- OpenAPI description: <https://watcher.trustsight.org/api/openapi.json>

## For agents

Use the documentation pages directly. If you need a compact map, fetch
`<https://docs.trustsight.org/sitemap.xml>` or the individual pages. The public
watcher API is GET-only, CORS-open, and rate-limited; a `429` response carries
`Retry-After`.
