<!-- name: Dependency Removal During A Build Change -->

- **Condition:** `checkdepends` loses an entry while `build()`,
  `prepare()` or `check()` changed in the same diff.

Dropping `checkdepends` eliminates the test-suite execution that would
catch a payload; the conjunction with a build change is what makes the
removal suspicious rather than hygienic. `optdepends` is not part of this
rule: it lists optional runtime suggestions, so removing one removes no
check and cannot hide a payload (yapfast dropped `vulkan-icd-loader` when
its renderer moved to GL). Measured on the locked benign corpus: the
`checkdepends` shape is what the published calibration floor covers, and
the fire-rate gate clears it for HIGH.
