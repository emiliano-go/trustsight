<!-- name: Adopted Source Executed -->

- **Condition:** A recorded takeover or adoption (`H086`, `H044`, `H074`, or a maintainer transition) coincides with a source identity the package did not use before and an execution of code fetched from that source (`H082`, `H083`, `H072`, `H081`, `H075`, or `H090`).

H088 catches the registry variant: an adopted recipe that now resolves code
from `npm`, `bun`, `pip` or another registry. This rule catches the declared
source variant used by the 2018 acroread and 2025 CHAOS RAT attacks: the
recipe points at an attacker-controlled repository or file and then runs it
during the build.

The source identity is the host plus the first path components, so a move
from `github.com/upstream/project` to `github.com/attacker/project` is a new
source even though both are GitHub. A benign adopter moving to a new upstream
can still be reviewed; the rule requires the execution sink, not merely the
source change.
