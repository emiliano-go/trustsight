<!-- name: Registry Or Index Override -->

- **Condition:** An added line in `prepare()`, `build()`, `check()`, `package()` or an install hook redirects a package manager away from its default registry: `npm --registry`, `npm_config_registry`, `.npmrc` `registry=`, `PIP_INDEX_URL`, `--index-url`/`--extra-index-url`, `UV_INDEX`, `CARGO_REGISTRIES_*`, `GOPROXY`, `GONOSUMDB`, `GOPRIVATE`, `gem sources --add`, `composer config repositories`, or `yarn`/`pnpm config set registry`.

A registry override is suspicious on its own because the default registry is
the ecosystem's trust anchor. It is a delivery chain when the same function or
install hook also resolves a package: the recipe chooses attacker-controlled
resolution before the build runs. A read-only query such as
`npm config get registry` is not an override.
