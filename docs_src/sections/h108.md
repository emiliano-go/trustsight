<!-- name: Service Or Cron Enable Command -->

- **Condition:** An added line in a build function or install hook runs `systemctl enable` (system or `--user`), `loginctl enable-linger`, `crontab`, `at`, `systemd-run --unit`, `update-rc.d`, or `chkconfig`.

`R054` catches a persistence file written outside the package root; this rule
catches the command that enables it. Shipping a unit and documenting how the
user may enable it is ordinary packaging. Enabling it during install changes
the running system without the user asking, and survives package removal in
the usual service-management sense.
