<!-- name: Indirect Sensitive Assignment -->

**HIGH** (weight 25) · category `evasion`

Fires when a sensitive makepkg variable (`DLAGENTS`, `COMPRESS*`,
`PACMAN_AUTH`, `CFLAGS`, `CXXFLAGS`, `LDFLAGS`, `MAKEFLAGS`, `RUSTFLAGS`,
`PATH`, `LD_PRELOAD`, `LD_LIBRARY_PATH`, `PYTHONPATH`) is assigned a value
that comes from another variable, a command substitution, or an array
expansion. Build-tool search paths configured from other variables
(`CMAKE_PREFIX_PATH`, `CMAKE_MODULE_PATH`, `PKG_CONFIG_PATH`, `ACLOCAL_PATH`,
`GIT_EXEC_PATH`, ...) are build plumbing, not loader paths, and stay quiet.

| Fires | Quiet |
|---|---|
| `DLAGENTS=("${_agents[@]}")` | `DLAGENTS=('http::/usr/bin/curl')` |
| `COMPRESSZST=$(get_compress)` | `CFLAGS="-O2 -march=x86-64"` |
| `CFLAGS="${_cflags[*]}"` | `LDFLAGS="-Wl,-O1 -Wl,--as-needed"` |
| `PACMAN_AUTH="${_auth}"` | `MAKEFLAGS="-j$(nproc)"` |

The evasion: `DLAGENTS=("${_agents[@]}")` looks like a pass-through but
the actual value was set in a function. Good PKGBUILDs assign literal
values to these variables.
